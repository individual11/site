A macOS menu bar app that shows the dev servers running on your Mac, grouped by project. Open one, copy its URL, or stop it along with everything it started. You can do all of that from the keyboard.

It reads running processes directly instead of probing ports, so each server shows its project, package and framework. Git worktrees get their own cards, so you can tell apart servers started from different branches.

It's free, MIT licensed and in beta, and I use it every day. The name is a pun. A head waiter keeps track of the servers. When you install it, there's a place card that reads "Your server will be right with you."
