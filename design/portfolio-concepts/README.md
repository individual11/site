# Portfolio concepts

Design explorations for the portfolio section. Open the HTML files directly in a browser; each one is self-contained. They are not part of the site build.

- `concepts-v1.html`: the first three scroll-driven particle concepts, each with designer notes. Published copy: https://claude.ai/artifact/7nnAz4idRvWvkhqgAexhkx
  - **Eleven**: chosen direction (two particle species: logic squares on a grid, creative dots on a flow field).
  - **Source → Render**: kept to revisit. Particles are code glyphs that compile into each project's image behind a green scanline, with a real build-time log. Open with `#source`.
  - **Equation**: parametric curves with scrubbable coefficients. Candidate easter egg. Open with `#equation`.
- `eleven-palettes.html`: three colour options for Eleven (replaces the green + violet pairing). Open with `#signal`, `#blueprint` or `#graphite`. Published copy: https://claude.ai/artifact/3y6JgnopNFcFH4ek1cAGNK
